# Snake Game / لعبة الثعبان

A classic Snake game for Android written in Java, drawn with a `SurfaceView` (no extra libraries).

- Tap to start, swipe to steer the snake.
- Eat the red food to grow; the snake speeds up as your score rises.
- Hitting a wall or your own body ends the game. Your best score is saved.
- Arabic and English text (follows the phone's language).

## Run
Open the `SnakeGame` folder in Android Studio and press **Run**, or build from the command line:

```
./gradlew assembleDebug
```

The APK ends up at `app/build/outputs/apk/debug/app-debug.apk`.
